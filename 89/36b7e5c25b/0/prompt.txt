### 2. `web/backend/config.py` — add auth settings

```python

```

### 3. `web/backend/auth.py` — **new** JWT + bcrypt utilities

- `verify_password(plain, hashed)` — bcrypt verify
- `create_access_token(subject)` — sign JWT with expiry
- `get_current_user` — FastAPI `Depends()` that validates `Authorization: Bearer` header, raises 401 on failure

### 4. `web/backend/routers/auth.py` — **new** login endpoint

- `POST /auth/login` — accepts `OAuth2PasswordRequestForm`, checks username + bcrypt hash, returns `{"access_token": "...", "token_type": "bearer"}`

### 5. `web/backend/main.py` — wire auth

- Mount auth router (public)
- Add `get_current_user` dependency to all protected routers (instances, targets, events, recordings, notifications, settings)
- Protect WebSocket endpoints: extract token from `?token=` query param

### 6. `web/frontend/src/api/client.ts` — auth header + 401 handling

- Add `getToken()` / `setToken()` / `clearToken()` using localStorage
- Inject `Authorization: Bearer` in `request()`
- On 401 → clear token, trigger `onAuthError` callback
- Add `auth.login(username, password)` and `auth.logout()`

### 7. `web/frontend/src/types/index.ts` — add `TokenResponse`

### 8. `web/frontend/src/components/LoginPage.tsx` — **new** login form

Centered card with username/password fields, dark SDR theme, error message on failure.

### 9. `web/frontend/src/App.tsx` — auth gate

- Track `token` state (init from localStorage)
- No token → `<LoginPage>`, valid token → `<AppLayout>`
- Pass `onLogout` to layout

### 10. `web/frontend/src/components/layout/Header.tsx` — logout button

Add LogOut icon button that clears token.

### 11. `web/frontend/src/utils/strings.ts` — German auth strings

### 12. WebSocket connections — pass `?token=` query param

Update spectrum and events WebSocket URLs in Dashboard components.
